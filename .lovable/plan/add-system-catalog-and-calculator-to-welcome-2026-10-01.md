# Add System Catalog and Calculator to `/welcome`

## Goal
Extend the active workflow presentation so visitors can see how FixMargin moves from selecting a tested system to a calculated, priced BoQ.

## Changes
- Add a **System Catalog** stage with system-family navigation, fire/acoustic/height filters, and a selected build-up preview.
- Add a **System Calculator** stage showing wall dimensions, waste allowance, board optimisation, material quantities, labour/material split, and the action to add the result to the project BoQ.
- Use the existing dark presentation style, FixMargin blue accent, and fictional Harbour Yard sample data.
- Update the workflow numbering and autoplay to include both new stages without changing application logic or existing pages.
- Add System Catalog and Calculator to the supporting capability grid.

## Validation
- Check both new stages manually in the presentation.
- Verify autoplay, pause, role views, mobile layout, horizontal overflow, console errors, and the latest build result.
